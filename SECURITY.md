# Security

## Reporting a vulnerability

Please report a vulnerability privately, through GitHub: on this repository's **Security** tab, select **Report a vulnerability**. Do not open a public issue for it.

You can expect a first answer within a week. Fixes ship as a new version of the plugin, which `claude plugin update spec-manager@spec-manager` installs.

## Supported versions

Only the latest version is supported.

## What the plugin does

Spec Manager runs on your machine and makes no network request. [What it runs, reads and sends](README.md#what-it-runs-reads-and-sends) lists every command it runs and every file it reads; [PRIVACY.md](PRIVACY.md) says what it keeps.
